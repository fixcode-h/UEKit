# AssetForge 更新日志

格式说明见仓库根目录的 `docs/changelog.md`（`scripts/check.mjs` 和发布流程依赖这个格式）。

## v1.0.0-beta.2

### Bug 修复
- **UE 5.8 下编译不过** — 属性差异里收集键名时把 `FJsonObject::Values` 当成 `FString` 键的表来用，5.8 的键已经是 `UE::FSharedString`，`GetKeys` 找不到匹配的重载。改成逐项取键名

## v1.0.0-beta.1

> 从原项目的 TkAssetForge 搬进 UEKit 后的第一版，只支持 UE 5.8。还没在本地用 UE 编译过，先发预发布（客户端查更新只认正式版）。

### 新功能
- **在 Agent 面板里管理** — 配置列表、同步状态、计划、属性差异、导入导出都搬到面板 UE 页的 AssetForge 页，UE 里不再有窗口。Agent 也能通过面板的 `ue_forge` 工具用同一套操作
- **导入导出不卡编辑器** — 面板发起的批量导入、导出变成后台作业，每帧做一点，进度实时推到面板，可以中途取消；多轮推进（引用别的配置的 UMG 等被引用者先导入）照旧
- **预览没存盘的改动** — 面板里改了配置还没保存时，也能直接看计划和属性差异
- **属性差异改成并排 JSON** — 列出导入后会变的每个属性和前后的值；和 git 上次提交的配置比较由面板取旧版本后传进来

### 改进
- **通信交给 UELink** — 去掉自己开的 HTTP 服务（原来没有令牌），操作挂在 UELink 的 `/rpc` 上（`forge.*`），共用令牌、只听本机
- **配置目录跟着项目的文档走** — JSON 配置是给人看和改的文件，不再和 UE 的 ini 混在 Config 里：项目外层同级有 `ProjectDoc/docs`（P4 / SVN 项目常见）就放 `ProjectDoc/docs/AssetForge`，否则放项目里的 `docs/AssetForge`。原来的配置挪过去即可，也可以在项目设置 → 插件 → Asset Forge 里指定目录（相对项目根，`../` 开头可以指到项目外）
- **同步清单挪到 `Saved/AssetForge/state.json`** — 它记的是本机资产文件的修改时间，不该进版本管理；原来配置根下的 `_forge-state.json` 第一次运行时自动复制过来
- **右键菜单「在 Agent 面板中显示」** — 代替原来的「在 Asset Forge 中显示」，面板开着时跳到对应的配置
- **去掉原项目的名字** — 类名、日志、示例里的 `Tk` 前缀和项目路径都换成通用的；依赖项目资产的自动化测试在资产不存在时跳过

### 注意
- 需要 UELink 2.2.0-beta.1 或更新的版本
- 装好后要在本地完整编译一次（Live Coding 不够）
