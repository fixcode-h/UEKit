# AssetForge 更新日志

格式说明见仓库根目录的 `docs/changelog.md`（`scripts/check.mjs` 和发布流程依赖这个格式）。

## v1.3.2-beta.1

### Bug 修复
- **「导入生成资源」不再让编辑器崩溃** — 配置和现有资产的属性完全一致（比如刚导入过）时，看属性差异会空指针崩溃；现在正常返回「没有差异」
- **状态树配置里节点写成非对象时不再崩溃** — 整理默认字段时先判空再读

## v1.3.1

### Bug 修复
- **打开工程时不再弹「插件为 5.4.0 构建、不兼容」** — 插件清单去掉了固定的引擎版本号，UE 5.4 到 5.8 打开工程都直接加载；只改了 `.uplugin`，C++ 没动

## v1.3.0

> 按用户要求直接发正式版：这一版及之前的预发布都还没在本地用 UE 5.4 / 5.8 完整编译验证过，装好后编译有问题请反馈。下面是从上一个正式版以来各预发布的汇总，细节见下面各 beta 节。

### 新功能
- **示例测试界面** — 插件自带多页面 UMG 界面、示例地图和 GameTest 场景，编辑器启动时装进配置根 `Test/`，在 AssetForge 页导入就能用来练习 GameTest 录制回放
- **给 Agent 的配置 schema** — `forge.kinds` 带 `kind` / `class` 返回配置的 JSON Schema 和类的可写属性

### 改进
- **支持 UE 5.4** — 以 5.4 为基准兼容 5.8；状态树只在 5.8 上可用，5.4 上其余 16 种资产照常用

### Bug 修复
- **UE 5.4 / 5.8 上的编译错误** — 材质、字体、动画状态机、控件蓝图、健康检查、属性差异的版本差异收进 `AssetForgeCompat.h`
- **导入作业在编辑器退出时按取消收尾、不重入**

### 注意
- 要 UELink 2.4.0 或更新（一起发的正式版）；装好后要在本地完整编译一次
- 示例资产依赖只在编辑器里加载的测试模块，`/Game/AgentTest` 要加进「永不烘焙的目录」

## v1.3.0-beta.1

> 云端改的，还没在本地用 UE 5.4 / 5.8 编译验证过，先发预发布。

### 新功能
- **示例测试界面** — 插件自带一套多页面 UMG 界面的配置（侧栏六个页、子页签、多层跳转和返回、九个弹窗、列表、格子、复选框、滑条、下拉框、输入框），编辑器启动时装进配置根的 `Test/`，在 AssetForge 页导入就生成 `/Game/AgentTest/AssetForge/WBP_ForgeSample`，用来练习 GameTest 录制回放
- **示例地图和 GameTest 场景** — 一并带一张示例地图（进图就显示示例界面，录完的场景回放能自己把界面带出来）和一个跑通跳页、弹窗、返回的 GameTest 场景（装进 GameTest 场景根的 `AssetForgeSample/`）；别的地图里 PIE 时控制台敲 `AssetForge.Sample` 打开 / 关掉界面
- **跳页不用写蓝图** — 示例界面的父类按控件名约定接好跳页、返回、弹窗、选中、提交（`Go_`、`Back`、`Open_` / `Close_`、`Pick_`、`Submit_`），自己照着加页面、加按钮也只改 JSON

### 注意
- 改过的示例文件插件升级时不覆盖，删掉的不会再装回来；不想要示例在项目设置 → 插件 → Asset Forge 里关掉「安装示例测试界面」
- 示例资产依赖只在编辑器里加载的测试模块，`/Game/AgentTest` 要加进「永不烘焙的目录」

## v1.2.0-beta.2

> 云端改的，按 UE 5.4.1 的编译报错修的，还没在本地重新编译验证过，先发预发布。

### Bug 修复
- **UE 5.4 上编译不过** — 材质、字体、动画蓝图状态机、控件蓝图、资产健康检查里用到的只有 5.8 才有的接口，在 5.4 上换成等效写法，差异都收在 `AssetForgeCompat.h`，5.8 照旧
- **UE 5.4 上的差别** — 资产健康检查只报逐资产的错误和警告（5.4 没有跨资产的校验消息）；改材质后的编译错误等材质编完再取

## v1.2.0-beta.1

> 云端改的，还没在本地用 UE 5.4 / 5.8 编译验证过，先发预发布。

### 改进
- **支持 UE 5.4** — 最低引擎从 5.8 降到 5.4，同一份代码 5.4 和 5.8 都能编：读 JSON 字段名、新建地图的世界分区设置这些版本差异收在 `AssetForgeCompat.h`
- **状态树只在 UE 5.8 上可用** — 状态树依赖 5.6 才有的 PropertyBindingUtils，5.4 上不编这一类，列表里没有「状态树」，其余 16 种资产照常用
- **要 UELink 2.4.0-beta.2 或更新** — 更早的 UELink 在 UE 5.4 上编不过

## v1.0.0-beta.1

> 从原项目的 TkAssetForge 搬进 UEKit 后的第一版，只支持 UE 5.8。还没在本地用 UE 编译过，先发预发布（客户端查更新只认正式版）。

### 新功能
- **在 Agent 面板里管理** — 配置列表、同步状态、计划、属性差异、导入导出都搬到面板 UE 页的 AssetForge 页，UE 里不再有窗口。Agent 也能通过面板的 `ue_forge` 工具用同一套操作
- **导入导出不卡编辑器** — 面板发起的批量导入、导出变成后台作业，每帧做一点，进度实时推到面板，可以中途取消；多轮推进（引用别的配置的 UMG 等被引用者先导入）照旧
- **预览没存盘的改动** — 面板里改了配置还没保存时，也能直接看计划和属性差异
- **属性差异改成并排 JSON** — 列出导入后会变的每个属性和前后的值；和 git 上次提交的配置比较由面板取旧版本后传进来

### 改进
- **通信交给 UELink** — 去掉自己开的 HTTP 服务（原来没有令牌），操作挂在 UELink 的 `/rpc` 上（`forge.*`），共用令牌、只听本机
- **配置目录跟着项目的文档走** — JSON 配置是给人看和改的文件，不再和 UE 的 ini 混在 Config 里：项目外层同级有 `ProjectDoc/docs`（P4 / SVN 项目常见）就放 `ProjectDoc/docs/AssetForge`，否则放项目里的 `docs/AssetForge`。原来的配置挪过去即可，也可以在项目设置 → 插件 → Asset Forge 里指定目录（相对项目根，`../` 开头可以指到项目外）
- **同步清单挪到 `Saved/AssetForge/state.json`** — 它记的是本机资产文件的修改时间，不该进版本管理；原来配置根下的 `_forge-state.json` 第一次运行时自动复制过来
- **右键菜单「在 Agent 面板中显示」** — 代替原来的「在 Asset Forge 中显示」，面板开着时跳到对应的配置
- **去掉原项目的名字** — 类名、日志、示例里的 `Tk` 前缀和项目路径都换成通用的；依赖项目资产的自动化测试在资产不存在时跳过

### 注意
- 需要 UELink 2.2.0-beta.1 或更新的版本
- 装好后要在本地完整编译一次（Live Coding 不够）
