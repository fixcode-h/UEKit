# GameTest 更新日志

格式说明见仓库根目录的 `docs/changelog.md`（`scripts/check.mjs` 和发布流程依赖这个格式）。

## v1.2.0-beta.7

> 云端改的，还没在本地用 UE 完整编译验证过，先发预发布。

### Bug 修复
- **回放点了按钮但界面没打开** — 真实鼠标点击在有的按钮上只被按下接住、没有触发点击（GM 入口点了打不开），后面的步骤一直等界面。`click` 默认改成不动鼠标：直接调按钮的 OnPressed → OnClicked → OnReleased，和录制时点开的效果一样

### 改进
- **点击默认不动鼠标** — 目标往上（不出所在界面）找最近的按钮、复选框、菜单锚点直接调；目标是整个子界面时点它里面唯一的按钮；都找不到时在控件位置发虚拟鼠标事件，系统光标不动，回放时可以照常用鼠标。要真实鼠标的步骤写 `via: "pointer"`，或在场景、运行设置里把点击方式改成真实鼠标

## v1.2.0-beta.6

> 云端改的，还没在本地用 UE 完整编译验证过，先发预发布。

### 新功能
- **阻挡界面自动处理** — 在项目的运行配置里标记 WBP（公告、新手引导、活动弹窗、断线重连……），跑测试时它一出现就自动关掉、调它的函数（例如「跳过」）或执行一条指令（GM），不再挡住后面的步骤；每次处理都记进那一步的结果和日志。运行配置是场景根下的 `_settings.json`，跟着场景进版本管理，面板 GameTest 页「运行设置」里可以编辑

### 改进
- **UI 等待默认不限时** — 点击、拖动、输入和「等界面出现 / 消失」默认一直等到界面出来，加载慢时不再 10 秒就报失败；真卡住了在面板上点停止。上限可以在运行配置、场景（`uiWaitTimeoutMs`）或单个步骤（`timeoutMs`）里设

## v1.2.0-beta.5

> 云端改的，还没在本地用 UE 完整编译验证过，先发预发布。

### Bug 修复
- **按住 Alt 点按钮，回放时按钮收到的是「没按 Alt」** — 回放用 `key phase=press` 按住的 Alt / Ctrl / Shift 以前只发了按键事件，之后点击、滚轮、按键事件里的修饰键还是去问操作系统，看不到它们，于是「按住 Alt 点 GM 按钮」回放成了普通点击，界面没打开。现在回放按住的修饰键会带进之后的所有输入事件
- **回放按键会抢走界面的焦点** — 没给 target 的按键以前每次都把焦点交给游戏视口，打开的界面可能因失焦关掉；现在焦点已经在游戏界面上时不动它，只有焦点在编辑器别的面板上才交给游戏视口

### 新功能
- **区分长按和单击** — 录制时按住超过 0.25 秒、期间没做别的操作的键录成一条 `key phase=tap holdMs=…`，回放按住同样久再松开；按住期间做了别的操作（按住 Alt 点按钮）才录成 press … release

### 改进
- **点击和每一步都写日志** — 每次真实指针点击写一行 LogGameTest（点了谁、屏幕坐标、按住了哪些键、按下被谁接住），每一步结束写一行结果，排查「录的时候点开了、回放没点开」不用猜
- **失败证据的日志不再被刷屏淹没** — `log.txt` 开头先列本次运行里 GameTest 的每一步和所有警告、错误；失败前后的日志里，某个类别刷屏（如每帧打印的 Lua 日志）时只留它的警告和错误，其余折成一句「省略了多少行」

## v1.2.0-beta.4

> 云端改的，还没在本地用 UE 完整编译验证过，先发预发布。

### Bug 修复
- **录制同一个界面的多个实例时回放点不中** — 活动按钮、主菜单入口这类同一个 WBP 摆了好几个的界面，如果不是用 UMG 的 AddChild 加进父面板（DynamicEntryBox、自定义列表、Lua 直接挂到 Slate 上），录制器以前找不到父界面，只写出 `WBP名:路径`，回放时几个实例都命中，等满超时报「歧义」。现在快照把这类子界面挂回它所在的容器下面，录制写成 `…容器/#类名#序号>…`，能唯一指回点的那一个

### 改进
- **回放按录制线索消歧** — 选择器命中同一个 WBP 的几个实例、步骤又带着录制的 `hint` 时，不再直接判失败：先排除不在屏上的（对象池里藏着的、折叠的），再按录制时的文字、位置挑最近的那一个，步骤结果里的 `picked` 写明怎么挑的；位置差太远或两个差不多近时照样报错，不瞎点。旧录制不用重录也能回放
- **录制时提前核对能不能挑回** — 选择器不唯一但按位置、文字挑得回来时，`hint` 里写 `pick`（说明），挑不回来才写 `ambiguous`，面板上黄色警告只留给真正有问题的步骤

## v1.2.0-beta.3

> 云端改的，还没在本地用 UE 完整编译验证过，先发预发布。

### Bug 修复
- **测试没跑完就停止时编辑器崩溃** — 一步失败自动留证据时，截图往一个空的结果对象里写字段，直接崩在 `CaptureGameWindow`。现在截图自己补上结果对象，留证据也传真的对象进去；截不了图只在证据里写原因
- **停止 PIE 那一帧还去碰正在关闭的世界** — 找游戏世界、截图、留证据都跳过正在拆的世界，按「没有游戏世界」报失败，不再去读快要销毁的视口和控件
- **控件高亮框在 PIE 停止或重开后可能读到已释放的内存** — 高亮层画的数据改成和层共享所有权，只从当初加上去的那个视口摘，视口换了就重建
- **子系统关闭途中又被驱动时不再崩** — 每帧驱动和失败留证据前先确认执行器、证据模块还在

## v1.2.0-beta.1

> 还没在本地用 UE 完整编译验证过，先发预发布。

### 新功能
- **失败时自动留证据** — 一步失败时自动截图、存下那一刻屏上的控件、记下失败前后 50 行日志，放进这次运行的 `failures/` 目录；步骤有选择器时再解析一次，找不到就列出候选，找到了就说明「控件在，但没点成」。报告里只记路径，面板的步骤详情直接显示。设置「失败时留证据」可以关掉
- **按标签批量运行** — `gt.run tag=smoke` 一个接一个跑带这个标签的全部场景（或 `scenarios` 给几份），某个失败不影响后面的，进度和每个场景的结果在作业状态的 `batch` 里，停止时整批取消
- **按场景记运行历史** — 每个场景文件最近 10 次的通过 / 失败记在 `Saved/GameTest/history.json`，编辑器重启后还在，`gt.history` 读取，面板在场景列表上画成历史条
- **核对选择器** — `gt.resolve` 只解析不执行，告诉你场景里每一步的选择器此刻能不能找到唯一的控件，找不到时给候选

### 改进
- **报告记下场景文件** — 跑场景文件时报告和运行摘要带上 `scenario`（相对场景根的路径），场景重名也能分清是哪个文件

## v1.1.0

> 录制不再只认按钮：按「谁接住了这次输入」认控件。按用户要求直接发正式版：发布前还没在本地用 UE 完整编译验证过，装好后编译有问题请反馈。

### 新功能
- **录制认得所有 UI 控件** — 不再只认按钮、复选框：自定义 WBP、BP 或 Lua 里重写了点击的控件、图片上绑的事件、列表条目、下拉菜单项，点下去都录成「点哪个控件」，并附上控件所在的 WBP、类型、文字和位置，面板上能直接看懂是哪个。不改引擎和项目代码
- **录制拖动、滚轮、打字** — 在控件上按住拖动录成 `drag`，滚轮录成 `wheel`（连着滚合成一条），在输入框里打的字录成 `type`，回车、退格这类键录成发给那个控件的 `key`
- **录制时拾取断言** — 按住 Ctrl+Alt 点一个控件，这次点击不传给游戏，录成一条「这个控件可见（文字是…）」的断言
- **`click` 真实点击并自动等待** — 先等控件出现、可见、可用、不再移动、没被别的东西挡住，再把光标移过去按下松开，并核对确实是这个控件接住了；等不到就说明卡在哪一条。默认最多等 10 秒（设置「UI 等待超时」）。旧的直接调用改成 `via: "code"`
- **新动作 `drag`、`wheel`，`type` 按真实键盘输入** — `type` 默认先全选再逐字输入（`append` 接着打），`key` 可以指定发给哪个控件
- **选择器能写到更多控件** — 列表条目（`列表[3]`、`列表[Id=5]`）、嵌套的 WBP（`外层>里层`）、没有 UMG 的 Slate 控件（`>>SButton[text=确定]`）、整个屏（`屏名:.`），屏名也可以写 WBP 资源路径
- **`gt.inspect` 查光标下的控件** — 返回命中路径、该写的选择器和核对结果、最近一次点击被谁接住；控制台命令 `GameTest.Inspect`

### 改进
- **UI 操作之间不再录等待** — 回放时 `click`、`type` 自己会等控件，录下来的秒数只会让慢机器失败、快机器白等；开始录制时打开 `keepPace` 可以照录

### 注意
- **场景格式升到 2** — 旧场景（格式 1）里的 `click`、`type` 读入时自动按 `via: "code"` 跑，行为不变；想换成真实点击，去掉 `via` 即可
- **打字录制需要 Slate 调试** — 没编 Slate 调试的进程（录制状态里 `handlerSource` 是 `hitPath`）按命中路径推断控件，打字录不到

## v1.0.0-beta.1

> 从原项目的 TkGameTest 搬进 UEKit 后的第一版，只支持 UE 5.8。还没在本地用 UE 编译过，先发预发布（客户端查更新只认正式版）。

### 新功能
- **录制回放** — 在游戏窗口里操作一遍，录成场景文件（场景根下的 `recorded/`），回放就是跑这份场景。点按钮录成「点哪个控件」而不是坐标，界面布局变了也能回放；改输入框、下拉框、滑条录最终值；点在游戏画面上和按键盘、手柄键录成真实按键，节奏用等待还原。录的时候可以插检查点（顺带截图），之后在面板里改成断言。用引擎公开的输入预处理器实现，不改引擎和项目代码
- **按键动作 `key`** — 按下、松开或点按一个键盘键、鼠标键，走和真实按键一样的输入路径，不需要知道项目的输入资产
- **在 Agent 面板里跑测试** — 场景列表、运行、逐步结果、截图、录制都在面板 UE 页的 GameTest 页；Agent 通过面板的 `ue_gametest` 工具用同一套操作。运行进度实时推到面板

### 改进
- **通信交给 UELink** — 去掉自己开的 HTTP 服务和端口设置（原来没有令牌，游戏进程里默认关着），操作挂在 UELink 的 `/rpc` 上（`gt.*`），共用令牌、只听本机；游戏进程里装了 UELink 就能用
- **CommonUI、GAS、EnhancedInput 拆成可选模块** — `stack.push/pop`、`ability.input`、`input.start/stop` 搬进各自的模块，主模块不再依赖这几个插件；动作清单里会标出哪些动作因为缺插件不可用，写了这些动作的场景会提示要开哪个插件
- **动作登记表** — 动作的说明、参数和实现在一处登记，不会再出现「清单里有、实现里没有」
- **返回内容有上限** — 快照、报告超过 12000 字时写进 `Saved/GameTest/responses/`，只返回路径，不撑爆 Agent 的上下文
- **场景可以自带步间隔** — 场景文件写 `stepDelayMs` 时覆盖项目设置（录制的场景写 0）
- **去掉原项目的名字** — 控制台命令改成 `GameTest.Step / Health / Actions`，测试名改成 `GameTest.*`，场景目录跟着项目的文档走（项目外层同级有 `ProjectDoc/docs` 就放 `ProjectDoc/docs/GameTest`，否则放项目里的 `docs/GameTest`，也可以在项目设置里指定）；测试探针只用插件自带的 C++ 类，不引用项目资产

### 注意
- 需要 UELink 2.2.0-beta.1 或更新的版本
- 编辑器里的 GameTest 窗口去掉了，改用 Agent 面板
- 测试探针控件挪到了 `GameTestTests` 模块（只在编辑器里加载），引用原来 `TkGameTest` 探针类的蓝图要重新指定父类
- `.uplugin` 把 CommonUI、GameplayAbilities、EnhancedInput 列成可选依赖：它们是引擎自带插件，启用 GameTest 时会一起打开
- 装好后要在本地完整编译一次（Live Coding 不够）
